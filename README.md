# Abhijeeth

> **Currently building — [Claw](https://github.com/Captain272/claw)**
> A system-wide voice copilot for macOS. Hold a hotkey, talk, it answers out loud — grounded in an Obsidian vault, aware of what's on screen, able to click, research, and run background agents. FastAPI core, Electron front-end, Claude Agent SDK, local STT/TTS, a three-tier memory model. Not a chatbot in a tab — it belongs to the machine.
